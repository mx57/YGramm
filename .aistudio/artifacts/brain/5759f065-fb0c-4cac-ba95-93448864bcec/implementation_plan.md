# План обновления YggGram: Честная отправка самому себе через сеть Yggdrasil, редизайн списков и 45+ реальных пиров

В соответствии с вашим требованием **полностью исключен локальный loopback (`127.0.0.1`)** при отправке сообщений самому себе. Проверка связи в чате «Избранное • Мой узел Yggdrasil» (или при отправке на свой собственный `200:...` IPv6 адрес / `Ed25519` ключ) теперь идет **строго через реальные внешние узлы сети Yggdrasil**.

---

## 1. Честная отправка сообщений самому себе через внешнюю сеть Yggdrasil

### Как работает маршрутизация «Самому себе» без локального обхода
1. **Полный запрет `127.0.0.1` / локального закорачивания**:
   - При отправке сообщения в чат **«Избранное • Мой узел Yggdrasil»** (или контакту со своим собственным `200:...` IPv6 / публичным ключом `Ed25519`) приложение **никогда** не шлет пакет на `127.0.0.1` и не имитирует доставку локально.
2. **Обязательное прохождение через активный публичный пир Yggdrasil**:
   - Для отправки сообщения самому себе проверяются:
     1. Физическое наличие интернета и отсутствие Авиарежима (`ConnectivityManager` + `AIRPLANE_MODE_ON`).
     2. Наличие хотя бы одного **реально подключенного публичного пира Yggdrasil** (`isConnected == true`) в вашей таблице маршрутизации.
   - Если в таблице маршрутизации нет ни одного подключенного пира или все пиры недоступны (например, заблокированы или нет интернета), сообщение **не доставляется** и честно остается в статусе `QUEUED_OFFLINE_SF` с уведомлением:
     *«Отправка через Yggdrasil невозможна: нет активных внешних пиров. Подключите рабочий пир во вкладке Сеть и DPI»*.
3. **Реальная сетевая транзакция через внешний узел Yggdrasil (`dispatchThroughYggdrasilPeerNode`)**:
   - Когда активный пир Yggdrasil выбран (например, `tls://ygg.zbin.eu:7743` или `tls://publicpeers.neilalexander.dev:443`), движок:
     1. Открывает реальное внешнее TCP/TLS/WSS соединение до удаленного публичного сервера Yggdrasil (с выбранным `SNI` и проверкой TLS-сессии).
     2. Выполняет рукопожатие протокола пиринга Yggdrasil (`META`-заголовок `yggdrasil` + криптографический кадр маршрутизации к вашему `Ed25519` ключу / `0200::/7` адресу) и отправляет зашифрованный `XChaCha20-Poly1305` пакет с `Hashcash PoW` через этот внешний узел.
     3. Получает ответный кадр от внешнего узла Yggdrasil по сети, вычисляет **реальный внешний сетевой RTT (в мс)** туда-обратно через интернет, увеличивает счетчики `TX/RX` байт у этого пира в таблице маршрутизации и верифицирует расшифровку AEAD-пакета.
     4. Только после успешного ответа внешнего пира Yggdrasil исходное сообщение получает статус `DELIVERED`, а в чат приходит входящее подтверждение с полным отчетом о маршруте:
        - Через какой именно внешний пир Yggdrasil прошел пакет (`URI` и страна узла);
        - Реальный сетевой пинг (RTT в мс) через этот пир;
        - Протокол туннелирования (`TLS` / `WSS` / `TCP`), `SNI` и статус проверки `XChaCha20-Poly1305`.

## 2. Исправление интерфейса, списков и диалогов

### Разделение экрана «Сеть и DPI» на 3 вкладки (`NetworkDpiScreen.kt`)
Вместо одной длинной прокручиваемой страницы экран разделяется на **3 отдельных раздела (Segmented Tabs)**:
1. **«Маршруты и Пиры»**:
   - Карточка состояния вашего узла Yggdrasil (`IPv6`, `Подсеть 300::/7`, число активных пиров, статус сети/авиарежима, кнопка **«Проверить связь (Эхо через Yggdrasil)»**).
   - Сворачиваемый живой журнал сетевых пакетов с кнопкой очистки.
   - Список подключенных пиров в таблице маршрутизации с кнопками **«+ Свой пир»** и **«Импорт из буфера»**.
2. **«Сканер узлов (45+ пиров)»**:
   - Фильтр по **16 странам** с индикацией количества узлов.
   - **Поиск по хосту / IP / городу / протоколу**.
   - **Сортировка пиров**: `По пингу (сначала быстрые, мс)`, `По стране`, `По аптайму`.
   - Переключатель `Только порт 443 / WSS`, кнопка `Сканировать пинг`, кнопка `+ Топ-3 живых` и удобное сворачивание/разворачивание длинного списка.
3. **«Обход ТСПУ»**:
   - Пресеты обхода блокировок, выбор разрешенного `SNI`-домена, отпечатка `uTLS ClientHello` и модулей маскировки трафика.

### Исправление карточек и экрана диалога (`ChatsScreen.kt`)
- **Карточки чатов и пиров без обрезания и наложений**:
  - Адреса `200:...` и `endpointUri` отображаются полностью читаемым моноширинным блоком с кнопкой копирования в 1 тап; кнопки управления вынесены в аккуратную панель действий.
- **Улучшения внутри чата (`ChatDetailPane`)**:
  - Кнопка **«Чат с собой (Тест через Yggdrasil)»** на стартовом экране и в списке чатов для мгновенной проверки сети.
  - В шапке любого чата — кнопка **«Пинг через Yggdrasil»**, проверяющая реальный RTT маршрута до узла.
  - В сообщениях со статусом `В очереди S&F` — **повторная отправка через сеть по нажатию (Retry on Tap)**.

## 3. Расширение каталога пиров для сканирования (45+ узлов в 16 странах + импорт)

- **Встроенный каталог из 45 реальных публичных пиров Yggdrasil в 16 странах**:
  - Россия (`RU`), Германия (`DE`), Финляндия (`FI`), Нидерланды (`NL`), Франция (`FR`), Польша (`PL`), Швеция (`SE`), Швейцария (`CH`), Великобритания (`GB`), Чехия (`CZ`), Эстония (`EE`), Казахстан (`KZ`), США (`US`), Канада (`CA`), Сингапур (`SG`), Япония (`JP`).
- **Безлимитная живая подгрузка из `publicpeers.neilalexander.dev/publicnodes.json`**:
  - Загружаются все доступные в онлайн-каталоге рабочие узлы (`tls://`, `tcp://`, `wss://`, `quic://`) без искусственного ограничения по количеству.
- **Массовый импорт пиров из буфера обмена**:
  - Позволяет вставить любой список пиров (несколько строк с `tls://...`, `tcp://...`, `wss://...`) и сразу просканировать их реальный пинг и подключить лучшие.
- **Сборка релизного APK**:
  - Обновление и проверка единственного релизного файла `apk-releases/YggGram-arm64-v8a.apk`.
